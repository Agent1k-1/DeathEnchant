# DeathEnchants

Плагин для Paper 1.20.1, Java 17. Пакет: `com.agent1k.deathenchants`.

## Использование

Обычный стол зачарований добавляет кастомные чары с вероятностью `table.chance`. Shift + ПКМ по столу с одним предметом в основной руке открывает меню с тремя явно подписанными предложениями кастомных чар. Меню расходует указанный уровень опыта полностью и 1–3 лазурита. Книжные полки в этом меню не учитываются. В стандартной подсказке клиента произвольные названия чар не отображаются.

Книги применяются через наковальню. Одинаковые уровни объединяются до следующего, в пределах максимума. Точило снимает кастомные чары, в том числе с книг. Ванильные проклятия сохраняются.

- `/deathenchants`, `/deathe`: справка.
- `/deathe give <ник> <id> [уровень]`: выдать книгу.
- `/deathe reload`: перечитать конфиги.
- `/deathe list`: список ID чар.

Выдача и перезагрузка требуют `deathenchants.admin`, по умолчанию доступного операторам.

## Конфигурация

`config.yml` задаёт вероятность чар в обычном столе и книгах лута, стоимость меню, уровни ванильных чар и ограничения эффектов. `loot.tables: []` означает все таблицы лута, включая таблицы вне данжей; для ограничения укажите ключи вроде `minecraft:chests/simple_dungeon`.

`enchant.yml` содержит название, максимальный уровень, целевые предметы, относительный вес выбора, значения эффекта по уровням и список строк описания каждой книги. Число строк не ограничено. Поддерживаются цвета `&` и `{level}`. Значения `experienced` — проценты бонуса опыта; `drill` и `vampirism` — вероятность. Остальные эффекты действуют постоянно при наличии чар.

`messages.yml` поддерживает `[message]`, `[title] заголовок|подзаголовок`, `[actionbar]` и `[sound] SOUND громкость тон`. Названия звуков соответствуют Bukkit Sound.

Опытный использует наибольший бонус среди основной руки, второй руки и брони. Пингер срабатывает при пересечении порога прочности. Посев требует семя в инвентаре. Лаваход временно заменяет лаву обсидианом. Дровосек обрабатывает связанные брёвна вверх, включая построенные игроками, до заданного лимита. Бур и дровосек вызывают обычное разрушение игроком, чтобы другие плагины могли отменить его.

## Настройка вероятности

У каждого зачарования в `enchant.yml` есть `chance: 100.0` (0–100). Сначала выбирается подходящее зачарование по `weight`, затем проверяется его `chance`. Неудача означает отсутствие чар; замена не выбирается. В обычном столе и луте сначала проверяется общий `table.chance` или `loot.chance`. В меню неудача оставляет соответствующий слот пустым. Команда выдачи не зависит от шансов.

В существующий серверный `enchant.yml` добавьте `chance` вручную к нужным секциям; без этого параметра используется 100%. Пингер ограничен инструментами даже для старого конфига и не действует на броне и оружии, кроме топоров, которые относятся к инструментам. Его `target` следует указать как `TOOLS`. Названия чар при выдаче и обновлении описания всегда серые; старые предметы не переписываются автоматически.

В версии 1.0.3 `vanilla-levels` задаёт максимумы объединения в наковальне. Стол сохраняет обычные ванильные уровни. Одинаковые уровни объединяются с повышением на один до лимита, разные — с выбором большего. Несовместимые чары не переносятся. Существующий уровень выше лимита не понижается. Сохраняются ванильные ограничения стоимости наковальни, включая «Слишком дорого».

Версия 1.0.1 обновляет описание старого снаряжения при входе игрока и операциях с инвентарём. Книги сохраняют описания. Очистка результата точила использует метаданные обоих входных предметов, даже если результат потерял их при ванильной обработке. Версию загруженного плагина можно проверить через `/version DeathEnchants`. Сборка и серверная проверка этого исправления не выполнялись.

## Цвета (1.0.2)

`com.agent1k.deathenchants.utils.HexUtils` обрабатывает обычные коды `&a`, `&7`, `&l`, `&r` и HEX `&#55FFAA`. Цвета поддерживаются в описаниях книг и текстовых действиях `[message]`, `[title]`, `[actionbar]`. Пример: `"[message] &#55FFAAГотово! &7Книга выдана."`. HEX требует шесть шестнадцатеричных цифр; некорректные последовательности остаются текстом. Значения YAML с цветами заключайте в кавычки. Названия зачарований по прежнему требованию отображаются серыми.
